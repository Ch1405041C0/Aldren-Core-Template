# Reglas para agentes de Aldren Studio Lab

EGM artifact directory: .dev/docs

- Usar estas instrucciones solo para trabajo de desarrollo del proyecto.
- Consultar el README y la documentación existente antes de proponer arquitectura.
- Tratar documentos de `.dev/docs/` como borradores; guardar las especificaciones aprobadas bajo `docs/designs/`.
- No asumir que las skills de EGM están instaladas por existir este archivo.
- No presentar una revisión Goldfish como independiente sin evidencia de subagentes con contexto conversacional fresco.
- No modificar código de producción ni desplegar cambios solo porque una revisión generó recomendaciones: requieren implementación, pruebas y revisión.
- No copiar prompts, agentes ni código del repositorio EGM a los proyectos; instalar el plugin original en el entorno compatible.
- No exponer secretos, datos personales o material confidencial a agentes sin necesidad y autorización.
